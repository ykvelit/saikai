# Introdução ao mundo de APIs

- Application Programming Interface 

- É uma forma de permitir a integração de uma aplicação com outra

- Na definição de APIs, o principal termo é interface

- Podemos pensar a interface como os termos contratuais que uma aplicação oferece para que outras aplicações possam se comunicar de forma programática

- Em síntese permitem a integração entre softwares distintos

- Definição de uma APIs e a integração entre as diversas aplicações de negócios

- A evolução do mundo das APIs diante das mudanças no processo de desenvolvimento de software e da TI em geral

- As APIs como elemento fundamental no processo de transformação digital

- O ciclo de vida de criação e gerenciamento das APIs em uma organização

## Web Services

- Um sistema de software projetado para suportar comunicação interoperável, máquina-a-máquina através de uma rede
    - W3C - World Wide Web Consortium

- APIs e Web Services
    - Os Web Services são voltados para atender a outras aplicações
    - Todo Web Service é uma API. Mas nem toda API é um Web Service
    - Web Services utilizam, basicamente, o protocolo HTTP como forma de comunicação (Web)

## Tipos de APIs

### APIs privadas

- As APIs são usadas exclusivamente dentro de uma determinada organização

- Os aplicativos são, em sua maioria, desenvolvidos para funcionários da empresa

- Integração de sistemas/aplicações da empresa e desenvolvimento de novos sistemas utilizando recursos existentes

### APIs de parceiros

- As APIs são promovidas abertamente, mas disponibilizadas apenas para parceiros de negócios conhecidos

- Clientes finais ou usuários corporativos são os públicos-alvo potenciais desses aplicativos

- O caso de uso mais comum dessas APIs é a integração de software entre duas organizações

### APIs públicas ou externas

- As APIs estão disponíveis para qualquer desenvolvedor terceiro. Podem ser abertas ou comerciais

- Os aplicativos são, em sua maioria, projetados para clientes finais

- Essa política de disponibilização de APIs permite aumentar a visibilidade e incentivar a inovação externa

## Gerenciamento do ciclo de vida de uma API

- Desenvolver / Testar
- Publicar
- Suportar / Manter

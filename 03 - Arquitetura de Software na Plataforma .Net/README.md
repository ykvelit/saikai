# Arquitetura de Software na Plataforma .Net

## Objetivos

- Tornar o aluno apto a, dado uma determinada demanda de construção de software, desenhar a arquitetura mais adequada ao contexto utilizando a plataforma .NET
- Contextualizar o aluno com as tecnologias, ferramentas, frameworks e plataformas de desenvolvimento de software da Microsoft
- Permitir com que o aluno atue como Arquiteto de Software utilizando a plataforma .NET
- Amadurecer os conhecimentos e experiências do aluno relativos a Arquitetura de Software com plataforma .NET 

## Emenda

- Utilizando a plataforma .NET para desenho de arquitetura e construção de software
- Alinhamentos e reflexões sobre novas tecnologias, infraestruturas e engenharias que interferem na forma de se desenhar a Arquitetura de um Software
- Entendimento do momento e do futuro da plataforma .NET

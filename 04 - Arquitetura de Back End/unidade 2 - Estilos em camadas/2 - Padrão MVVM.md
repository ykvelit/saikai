# Padrão MVVM

- Model View View Model
- Evolução do MVC
- Evolução gráfica das interfaces
- Web
- Popularizado com o Angular
- Modelo de construção muito usado pelo js
- User > View > ViewModel > Model
- ViewModel representa um cache para a visão
    - Caso o dado não esteja disponível, será feito uma requisição com o modelo
- Menor tráfego de rede
- Renderização em cache no navegador

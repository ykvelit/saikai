# Arquitetura de Back End

## Objetivo

- Capacidade de tomar decisões técnicas baseadas em um racional arquitetural
- Conhecimento dos padrões arquiteturais  MVC e VVM
- Conhecimento das abordagens de construção de software de DDD e Arquitetura Limpa
- Conhecimento dos estilos de camadas, eventos, pipelines, serviços, microsserviços
- Conhecimento de tecnologias de API, serviços e nuvens para o desenvolvimento de backend de aplicações

## Unidades de ensino

### Unidade 1

- Estilos Arquiteturais Comuns

### Unidade 2

- Estilos em Camadas
- MVC
- MVVM
- DDD
- Arquitetura Limpa

### Unidade 3

- Estilo Arquitetural de API

### Unidade 4

- Estilo Arquitetural de Microsserviços e Eventos

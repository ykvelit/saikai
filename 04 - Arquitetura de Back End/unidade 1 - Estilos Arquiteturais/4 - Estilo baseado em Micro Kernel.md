# Estilo baseado em Micro Kernel

- Um micro kernel é um tipo de kernel de sistema operacional que gerencia apenas as funções básicas, como gerenciamento de memória, agendamento de tarefas e comunicação entre processos. Ele difere de um kernel monolítico, que inclui a ógica para todas as funções do sistema operacional em um único componente

- As principais responsabilidades de um micro kernel em um sistema operacional são gerencias a memória, o agendamento de tarefas e a comunicação entre processos, enquanto outros componentes do sistema operacional são executados como processos separados no espaço do usuário

- Na arquitetura de micro kernel, os processos no espaço do usuário interagem com o micro kernel por meio de mecanismos de comunicação entre processos

- Núcleos de extensibilidade sem alteração do núcleo principal

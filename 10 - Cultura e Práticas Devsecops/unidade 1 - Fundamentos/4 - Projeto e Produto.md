# Projeto e produto

- Projeto
    - O projeto é caracterizado por ser um empreendimento único que conduzido por pessoas possa atingir seus objetivos definidos, respeitando os parâmetro de custo, prazo e escopo
    - Possui início, meio e fim claramente definidos

- Produto
    - O produto é orientado a valor, tendo o foco no cliente
    - É um processo contínuo 
    - Em uma relação de produto e projeto, o projeto é um processo é o produto é o resultado deste processo
    - O sucesso de um projeto não implica necessariamente no sucesso de um produto

- Qualidade do gerenciamento do projeto
    - Escopo
    - Prazo
    - Custo

- Valor para o cliente
    - Usabilidade
    - Design
    - Desempenho

- Mindset
    > O problema não é que nossas organizações percebam que precisam se transformar. O problema é que as organizações estão usando estruturas gerenciais e modelos de infraestrutura anteriores para gerenciar seus negócios nesta
    > Mike Kersten, 2018

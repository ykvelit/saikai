- Metodologias de Pentest
    - NIST SP 800-115
    - PTES
    - OSSTMM
    - Penetration Test Framework (PTF)
    - EC-COUNCIL
    - OWASP
    - CESG CHECK (UK)

- Fases típicas do teste de intrusão/pentest
    - Análise e Reconhecimento
    - Identificação de Ameaças
    - Detecção de Vulnerabilidades
    - Avaliação das Vulnerabilidades
    - Exploração de Vulnerabilidades 
    - Relatório

- OWASP
    - Open Web Application Security Project
    - O OWASP é amplamente utilizado e possui três métodos para testes de segurança
        - OWASP Web Security Testing Guide
        - OWASP Mobile Security Testing Guide
        - OWASP Firmware Security Testing Methodology
    - Fases
        - Análise e Reconhecimento
        - Autenticação
        - Autorização
        - Gerenciamento da Sessão
        - Validação de Input
        - Tratamento de Erros
        - Criptografia Fraca
        - Lógica de Negócio
        - Client-side 
        - Teste de API

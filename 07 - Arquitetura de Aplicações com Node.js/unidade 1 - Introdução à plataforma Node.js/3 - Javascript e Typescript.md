# Javascript e Typescript

## Javascript

- Linguagem de programação interpretada (no caso, pela engine do browser)
- Utilizada para escrever aplicações na plataforma Node.js
- Linguagem fracamente tipada
    - Possível declarar uma variável que pode receber qualquer tipo a qualquer momento
- Adiciona interatividade nas aplicações web
- Possui diversas especificações:
    - EcmaScript 1, 2, 3....7, 8
    - As especificações são definidas por um conjunto de especialistas da comunidade open-source (Google, Mozilla, Microsoft...) e definem as funcionalidades presentes no Javascript

## Typescript

- Linguagem de programação que extende os recursos originais do JavaScript
- Adiciona tipagem estática opcional e inúmeras outras funcionalidades que trazem mais robustez à nossa aplicação
- Compatível com todos os recursos mais recentes do javascript
- Necessita um compilador que traduz o Typescript para Javascript, uma vez que o node trabalha exclusivamente com Javascript

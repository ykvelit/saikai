## SQLite

- Banco de dados embarcado na aplicação - o arquivo com os dados fica junto com o código-fonte

- Nenhuma configuração necessária, basta criar um arquivo e pronto

- Utiliza linguagem SQL com a grande maioria das principais instruções e é compatível com todos os sistemas operacionais

- Ideal para uso de aplicações de teste ou aplicações de pequeno porte em geral

- A grande vantagem do SQLite sobre outras opções como o MySQL é a facilidade de integração com aplicações de qualquer linguagem e a possibilidade de desenvolver uma aplicação sem configurações complexas de banco de dados

- Muito usado para
    - IoT
    - Testes
    - Aplicativos móveis

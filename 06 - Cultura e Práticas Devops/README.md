# Cultura e Práticas Devops

## Objetivos

- Compreender o que é o DevOps e os seus benefícios de negócio

- Conhecer os princípios

- Conhecer práticas técnicas, práticas de processo e práticas culturais DevOps

- Conhecer e comparar ferramentas para o suporte a implantações DevOps 

- Praticar com ferramentas básicas para uso em DevOps

## Métodos

- Aulas expositivas através de vídeos
- Questões de fixação
- Questões de revisão
- Exercícios abertos para análise de problemas
- Interações no portal com alunos 

## Ementa
- Caminhos do DevOps
- CALMS
- Automação de Builds

- Infraestrutura como Código
- Monitoração

- Cultura DevOps

- FinOps

# Práticas Técnicas Devops

Essa unidade oferta com uma definição clara de DevOps,  explorando suas capacidades técnicas, ferramentas como GitHub e GitHub Actions, e a implementação prática de pipelines com o uso Node e Express. Além disso, aborda tópicos como Pipelines DevOps, automação de builds, testes e entregas, diferenças entre entrega contínua e implantação contínua, observabilidade e atividades exploratórias de aprendizado.

Como seu instrutor, estou aqui para guiá-lo através dos seguintes vídeos essenciais que compõe essa unidade.

1.1 Afinal, o que é o DevOps: Neste vídeo introdutório, definiremos o que é DevOps, explorando sua origem, princípios e por que ele é vital na era moderna do desenvolvimento de software.

1.2 Capacidades Técnicas DevOps: Aqui, abordaremos as habilidades técnicas necessárias no DevOps, incluindo automação, integração contínua e colaboração entre equipes.

1.3 GitHub e GitHub Actions: Este vídeo foca no GitHub e nas GitHub Actions, explicando como essas ferramentas facilitam a colaboração e automação em projetos de desenvolvimento.

1.4 - 1.9 Exemplo Node, Express e GitHub Actions: Em uma série de vídeos, guiarei você através da implementação de um projeto real usando Node, Express e GitHub Actions, demonstrando cada etapa do processo.

1.10 Pipelines DevOps: Neste vídeo, exploraremos os Pipelines DevOps, uma abordagem estruturada para automatizar o fluxo de trabalho de desenvolvimento.

1.11 Automação de Builds & 1.12 Automação de Testes: Aqui, discutiremos a importância da automação em builds e testes, e como ela contribui para uma entrega mais eficiente.

1.13 Automação de Entregas: Este vídeo abordará a automação de entregas, explicando como ela acelera o ciclo de vida do desenvolvimento.

1.14 Entrega Contínua versus Implantação Contínua: Vamos explorar a diferença entre entrega contínua e implantação contínua, dois conceitos fundamentais no DevOps.

1.15 Observabilidade: Neste vídeo, focaremos na observabilidade no DevOps, incluindo monitoramento, diagnóstico e análise de sistemas.

1.16 Atividades Exploratórias de Aprendizado: Este vídeo apresentará atividades práticas que complementarão sua compreensão em DevOps.

1.17 Slides Unidade 1 & 1.18 Leitura Complementar: Não deixe de conferir os slides e a leitura complementar, que aprofundarão seu conhecimento nos tópicos abordados.

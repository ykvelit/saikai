# Capacidades Técnicas DevOps

- Gestão de Configuração de Código
    - Prática para gerir código fonte, arquivos de infraestrutura como código, para controle de versionamento, linhas de base e rastreabilidade
    - Repositório git
    - Gestão colaborativa de código

- Automação de Testes
    - Prática para a execução automatizada de testes em diferentes níveis e objetivos

- Integração Contínua
    - Prática para construção automatizada de executáveis robustos (builds)

- Entrega Contínua
    - Prática para a implantação segura de executáveis em ambientes de homologação e produção (releases)

- Infraestrutura como Código
    - Prática para executar provisionar ativos de infraestrutura e nuvens através de código

- Conteinerização
    - Prática para virtualização de ambientes, servidores e software através de contêineres leves

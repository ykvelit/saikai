# GitHub e GitHub Actions

## GitHub

1. Repositório Git de nuvem e um provedor de serviços
2. Gestão e armazenamento de repositórios Git
3. Armazenamento push/pull 
4. Gestão colaborativa de código (pull requests)
5. Automação e CI/CD (GitHub Actions)

## GitHub Actions

### Workflows

- Vinculado a um repositório GitHub
- Contém um ou mais Jobs
- Ativado através de eventos

### Jobs

- Define o ambiente de execução (Runner)
- Contém um ou mais passos
- Roda em paralelo ou sequencialmente
- Pode ser condicional

### Steps

- Executa um script de linha de comando (Shell script) ou uma ação (Action)
- Pode executar ações de terceiros ou personalizadas
- Passos são executados em ordem
- Podem ser condicionais

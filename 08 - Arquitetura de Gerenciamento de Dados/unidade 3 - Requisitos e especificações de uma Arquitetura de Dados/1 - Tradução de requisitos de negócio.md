# Tradução de requisitos de negócio

## Como identificar requisitos de negócio

- Estratégia empresarial
    - Missão, Visão e Valores
    - Abordagem para as 4 perspectivas
        - Finanças
        - Clientes
        - Interno
        - Inovação
    - Identificar as prioridades estratégicas
    - Objetivos empresariais e seus fundamentos
    - Indicadores, métricas e metas
    - Projetos e iniciativas em cuso e planejadas

- Estratégia de dados
    - Resultado e geração de valor
        - Aplicação
        - AI e Ciência de dados
        - Dashboards
    - Fundação técnica
        - Plataforma
        - Integração
        - Governança
        - Segurança
        - FinOps
    - Cultura
        - Capacitação
        - Gestão de mudança

### Onde estamos

- Conhecer o que existe
    - Entrevistas com todos os profissionais envolvidos nos processos
    - Análise da documentação existente
    - Explorar os dados existentes e suas estruturas

- Mapeamento dos processos AS IS
    - Desenhar os processos
    - Identificar as estruturas de dados existentes

### Onde queremos chegar

- Estruturas as necessidades e pontos de melhorias
    - Descrição clara dos objetivos a atingir
    - Identificar e registrar as prioridades

- Mapeamento dos processos TO BE
    - Desenhar os processos
    - Identificar as estruturas de dados necessárias

### Como chegar lá

- Gap Analysis
    - Avaliar o que falta entre os AS IS e o TO BE 

- Construção do documento de requisitos de negócio

## Decomposição dos requisitos em especificações técnicas

- Identificar as fontes de dados
- Identificar as entidades e atributos
- Estabelecer relacionamentos e regras dos dados
- Desenhar os modelos de dados e esquemas
- Alinhar a arquitetura com a estratégia de dados
- Rever e validar os requisitos de dados

## Requisitos não funcionais - indicadores, métricas e alarmística

- Infraestrutura
    - Redes
    - Disponibilidade dos serviços
    - Acessos
    - Tentativas de invasão

- Processamento
    - Quantidade de registros processados
    - % de utilização de CPU por processo

- Integração
    - Quantidade de registros integrados
    - Tempo de integração por registro

- Governança
    - Quantidade de entrada em produção de novos processos
    - Políticas violadas

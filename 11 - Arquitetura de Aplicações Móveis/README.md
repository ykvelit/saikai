# Cultura e Práticas Devsecops

## Objetivos 

- Compreender os princípios fundamentais da arquitetura de aplicações móveis, capacitando-se a estruturar aplicações de maneira eficiente

- Identificar e aplicar requisitos arquiteturais específicos para o desenvolvimento de aplicações móveis, garantindo desempenho, segurança e compatibilidade entre plataformas

- Analisar diferentes tipos de aplicações móveis e suas respectivas estruturas de interface, com foco na usabilidade e na experiência do usuário

- Explorar padrões arquiteturais adequados para aplicações móveis, aplicando frameworks apropriados e seguindo boas práticas de desenvolvimento

- Avaliar a utilização de Web Workers e Progressive Web Apps (PWAs) no contexto do desenvolvimento moderno, explorando suas vantagens para otimização de desempenho e acessibilidade

## Ementa

- Requisitos Arquiteturais para aplicações móveis
- Estrutura da interface em dispositivos móveis
- Tipos de aplicações móveis
- Padrões arquiteturais para aplicações móveis
- Web Workers e Progressive Web Apps (PWA)
- Frameworks e Middlewares para aplicações móveis

# Desafio 3: Comparar as vantagens e desvantagens de utilizar um framework híbrido (React Native, Flutter) em relação ao desenvolvimento nativo

## Objetivo

- Para o Desafio 3, o objetivo é que o aluno explore as diferenças entre o desenvolvimento nativo e o desenvolvimento com frameworks híbridos, como React Native e Flutter

- Esse desafio é uma análise comparativa para que o aluno compreenda as principais vantagens e desvantagens desses métodos, entendendo em quais contextos cada um é mais apropriado

- Isso será essencial para fazer escolhas estratégicas em projetos futuros

## Objetivos do desafio

- Objetivo
    - Analisar e comparar as vantagens e desvantagens de desenvolver aplicativos móveis nativamente (usando Swift para iOS e Kotlin para Android) versus usando um framework híbrido (React Native ou Flutter)

- Resultados Esperados
    - Descreva um relatório destacando os seguintes pontos
        - Comparação de performance, desenvolvimento de interface, custo e manutenção entre ambas as abordagens
        - Conclusão com uma recomendação sobre a escolha do tipo de desenvolvimento ideal para diferentes cenários de aplicação

## Etapas do desafio

### Pesquisa Inicial sobre Frameworks Híbridos e Nativos

- Frameworks Híbridos
    - Deve estudar o conceito de frameworks híbridos, com foco em Flutter e React Native, compreendendo como eles funcionam para criar um código-fonte único que pode ser compilado para múltiplas plataformas (iOS e Android)

- Desenvolvimento Nativo
    - Deve-se estudar como o desenvolvimento nativo é feito, aprendendo as bases de desenvolvimento com Swift para iOS e Kotlin para Android, e suas vantagens em termos de acesso direto aos recursos do dispositivo


### Definição de Critérios de Comparação

- Para uma análise bem estruturada, devem definir os critérios de comparação

- Os principais critérios a serem considerados 
    - Performance
        - Como se comportam aplicativos nativos em comparação com híbridos em termos de velocidade e uso de memória?
        - Impacto na fluidez de animações e transições de tela
        - Comparar como a performance é afetada em dispositivos de entrada (modelos mais básicos) versus dispositivos de ponta

    - Interface de Usuário (UI) e Experiência do Usuário (UX)
        - Como o design de UI/UX se adapta em cada abordagem?
        - Frameworks híbridos conseguem replicar fielmente o design e o comportamento nativo de cada sistema operacional?
        - Flexibilidade para criar interfaces específicas para iOS e Android, respeitando diretrizes como Material Design (Android) e Human Interface Guidelines (iOS)

    - Tempo e Custo de Desenvolvimento
        - Comparar o tempo necessário para desenvolver uma aplicação nativa versus uma híbrida
        - Considerar o impacto de usar um único código-fonte (híbrido) em relação a manter dois códigos separados (nativo)
        - Estimar o custo de desenvolvimento e a economia que pode ser obtida ao usar um framework híbrido

    - Acesso a Recursos Nativos do Dispositivo
        - Comparar a facilidade e a eficiência do acesso a funcionalidades do dispositivo, como câmera, GPS, armazenamento, etc
        - Examinar a compatibilidade de plugins e pacotes em React Native e Flutter para acessar APIs nativas e se há limitações ou dificuldades na integração
    
    - Manutenção e Atualizações
        - Avaliar como cada abordagem facilita ou dificulta a manutenção e atualização do app, incluindo a integração de novas funcionalidades e resolução de bugs
        - Comparar como cada abordagem lida com atualizações de sistema operacional, especialmente em termos de compatibilidade com novas versões do iOS e Android

### Elaboração de Relatório ou Apresentação

- Deve organizar suas descobertas em um formato claro e objetivo, destacando as principais conclusões para cada critério de comparação
    
- Estrutura sugerida para o relatório/apresentação
    - Introdução
        - Visão geral do objetivo do desafio e uma breve explicação do que são frameworks híbridos e desenvolvimento nativo
    - Comparação por Critérios
        - Cada critério de comparação (performance, UI/UX, custo, etc.) pode ter uma seção ou slide específico, detalhando os prós e contras de cada abordagem
    - Conclusão
        - Resumo das principais vantagens e desvantagens de cada abordagem e uma recomendação final
            - Exemplos de cenários ideais para cada abordagem
                - Aplicativos que requerem alto desempenho e recursos avançados do dispositivo são mais indicados para desenvolvimento nativo
                - Aplicativos voltados para múltiplas plataformas com foco em velocidade de entrega podem ser mais adequados para frameworks híbridos

### Conclusão

- Após finalizar o relatório
    - Compartilhar com seus colegas, discuta com alguém do seu mercado de trabalho
    - Refletir sobre como escolheria entre um framework híbrido e desenvolvimento nativo em um projeto real

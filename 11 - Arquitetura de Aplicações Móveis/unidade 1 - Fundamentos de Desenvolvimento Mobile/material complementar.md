# Material Complementar

## Notas de aula

### Fundamentos de Desenvolvimento Mobile

- Definição
    - Desenvolvimento mobile refere-se ao processo de criação de software especificamente projetado para dispositivos móveis como smartphones e tablets
    - Envolve o uso de plataformas como iOS, Android e frameworks multiplataforma

- Arquitetura
    - A arquitetura de desenvolvimento pode variar entre nativa, web ou híbrida, cada uma com vantagens e desvantagens específicas

- Ferramentas de Desenvolvimento
    - Para iOS, utiliza-se Swift/Objective-C e o Xcode; para Android, Kotlin/Java e o Android Studio
    - Outras ferramentas incluem frameworks como React Native, Flutter e Xamarin

### Dispositivos Móveis

- Tipos de Dispositivos
    - Smartphones, tablets, wearables (ex: smartwatches) e e-readers (ex: Kindle)

- Capacidades
    - Mobilidade, acesso à internet, integração com sensores (GPS, acelerômetro) e poder de processamento para rodar aplicativos complexos

- Evolução e Impacto
    - Os dispositivos móveis têm superado desktops em termos de uso para acesso à internet, mudando a forma como consumimos conteúdo e realizamos atividades do dia a dia

### Requisitos Arquiteturais para Aplicações Móveis

- Componentes de Arquitetura
    - Backend (APIs), Frontend (UI/UX), e integração com serviços de terceiros (bancos de dados, autenticação)

- Padrões Arquiteturais
    - MVC (Model-View-Controller), MVVM (Model-View-ViewModel), MVP (Model-View-Presenter) e Clean Architecture

- Considerações de Desempenho
    - Aplicativos móveis devem ser leves, eficientes e consumir poucos recursos, como memória e bateria

### Estrutura da Interface em Dispositivos Móveis

- Princípios de Design
    - Consistência, simplicidade e acessibilidade são essenciais para criar interfaces eficazes

- Componentes Comuns
    - Botões, barras de navegação, menus e campos de texto
    - Cada componente deve ser projetado para ser intuitivo e fácil de usar em telas pequenas

- Layouts Adaptativos
    - Garantir que a interface seja responsiva e se adapte bem a diferentes tamanhos de tela, especialmente em dispositivos de vários formatos (smartphones, tablets)

### Tipos de Aplicações Móveis

- Aplicações Nativas
    - Desenvolvidas especificamente para uma plataforma (iOS ou Android) utilizando as linguagens e ferramentas oficiais

- Aplicações Web
    - Acessadas através de navegadores móveis, não precisam ser instaladas e são desenvolvidas com HTML, CSS e JavaScript

- Aplicações Híbridas
    - Combinam características de aplicativos nativos e web, geralmente desenvolvidas com frameworks como React Native ou Flutter

# Oficina 2: Criar Wireframes para Aplicações Móveis usando Ferramentas como Figma ou Adobe XD

## Objetivo
A oficina tem como objetivo incentivar e estimular sua criatividade a desenvolver wireframes para aplicativos móveis, utilizando ferramentas de design populares, como Figma e Adobe XD. Ao final, terão desenvolvido wireframes de baixa fidelidade para uma aplicação móvel, compreendendo melhor o fluxo de navegação e a organização de elementos da interface.

## Pré-requisitos
- Computador com acesso à internet.
- Conta gratuita criada no Figma ou Adobe XD.
- Conhecimento básico de interfaces móveis (prévia leitura dos princípios de design de interface é recomendada).

## Passos para a Criação de Wireframes:
### 1. Introdução ao Wireframe

- O que é um wireframe?
    - Um wireframe é uma representação simples e esquemática de um layout de página, focando na estrutura e na disposição de elementos da interface, sem detalhes de estilo ou design final.

- Por que criar wireframes?
    - Wireframes ajudam a planejar a experiência do usuário (UX) e a hierarquia visual, facilitando a comunicação entre designers e desenvolvedores.

### 2. Escolha da Ferramenta

- Ferramentas sugeridas:
    - Figma:
        - Plataforma: Web e Desktop (Windows, macOS).
        - Vantagens: Colaboração em tempo real, uso gratuito com recursos robustos.
        - Acesso: Figma(https://www.figma.com/pt-br/)
    - Adobe XD:
        - Plataforma: Desktop (Windows, macOS).
        - Vantagens: Integração com o ecossistema Adobe, prototipagem rápida.
        - Acesso: Adobe XD(https://helpx.adobe.com/br/support/xd.html)

### 3. Criação de Wireframes no Figma

- Passos para iniciar:
    - Acesse o Figma e crie uma conta.
    - Após logar, crie um novo arquivo de design clicando em New File.
    - Defina a tela de um dispositivo móvel:
    - Utilize o Frame Tool (F) para criar um quadro com o tamanho da tela de um dispositivo móvel (ex: iPhone ou Android).
    - Adicione blocos representando elementos básicos:
    - Retângulos e linhas para representar botões, menus e áreas de conteúdo.
    - Utilize caixas de texto para definir áreas de texto e títulos.

- Dicas de uso:
    - Componentes reutilizáveis: Crie elementos de interface que podem ser reutilizados em diferentes telas.
    - Auto Layout: Utilize o recurso Auto Layout para manter consistência e responsividade no layout.

### 4. Criação de Wireframes no Adobe XD

- Passos para iniciar:
    - Faça o download do Adobe XD e instale em seu computador.
    - Abra o Adobe XD e crie um novo documento selecionando o tamanho de tela para dispositivos móveis.
    - Utilize as ferramentas de Shapes (retângulos, círculos, etc.) para desenhar os elementos da interface.
    - Adicione texto e organize os elementos de maneira lógica, simulando o fluxo de navegação de uma aplicação.

- Dicas de uso:
    - Repeat Grid: Utilize o Repeat Grid para criar listas e grupos de itens repetidos, como cards de produtos ou listas de contatos.
    - Prototipagem rápida: Faça protótipos conectando as telas criadas e simule interações básicas entre elas.

### 5. Prática: Criação de um Wireframe de Aplicativo Móvel

- Tarefa proposta:
    - Crie o wireframe de um aplicativo de e-commerce simples.
    - As telas devem incluir:
        - Tela de login.
        - Página de catálogo de produtos.
        - Tela de detalhes de produto.
        - Carrinho de compras.
    - Utilize as ferramentas de blocos simples (caixas, botões e textos) para organizar os elementos em cada tela.

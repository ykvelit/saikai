# Bibliografia

- Murphy, Mark L. - The Busy Coder’s Guide to Android Development (CommonsWare, 2020)
    - Este livro é uma referência essencial para o desenvolvimento de aplicações Android, abordando desde o básico até conceitos avançados de arquitetura e padrões de desenvolvimento

- Zammetti, Frank - Modern Web Development with HTML5, CSS3, and JavaScript (Apress, 2020)
    - Focado em desenvolvimento web e PWAs, é uma excelente introdução para quem quer entender as tecnologias por trás de apps híbridos e web

- Knapp, E. - Flutter for Beginners: An Introductory Guide to Building Cross-Platform Mobile Applications (Packt, 2020)
    - Um guia passo a passo para começar com Flutter, abrangendo desde o desenvolvimento básico até conceitos arquiteturais

- Haverbeke, Marijn - Eloquent JavaScript: A Modern Introduction to Programming (No Starch Press, 2018)
    - Um excelente livro para compreender JavaScript, que é crucial para o desenvolvimento web e híbrido

- Nielsen, Jakob & Budiu, Raluca - Mobile Usability (New Riders, 2012)
    - Um clássico para entender os princípios de design de interface voltados para dispositivos móveis e a importância da experiência do usuário

- Roberts, Adam & Dave MacLean - Learning React Native: Building Native Mobile Apps with JavaScript (O'Reilly Media, 2019)
    - Um livro introdutório sobre o React Native, focando no desenvolvimento de aplicativos móveis híbridos com esse framework

- Farrell, Joe - MVVM in Xamarin.Forms (Apress, 2020)
    - Excelente recurso para quem quer aplicar o padrão MVVM em um contexto móvel, especificamente com Xamarin

- Moore, Kevin & Smith, Philip - Pro Android with Kotlin: Developing Modern Mobile Apps (Apress, 2019)
    - Este livro foca no desenvolvimento Android com Kotlin, cobrindo boas práticas e arquitetura

- Pressman, Roger S. - Software Engineering: A Practitioner's Approach (McGraw-Hill, 2020)
    - Oferece uma visão geral sobre requisitos arquiteturais e melhores práticas no desenvolvimento de software, com enfoque em escalabilidade e segurança

- Wolff, Benjamin - Progressive Web Apps with Angular: Create Responsive, Fast and Reliable PWAs Using Angular (Apress, 2020)
    - Um guia completo sobre a implementação de PWAs, com exemplos práticos de como integrar com frameworks populares

- Schmidt, Douglas C. & Michael Stal - Pattern-Oriented Software Architecture: Patterns for Concurrent and Networked Objects (John Wiley & Sons, 2013)
    - Aborda os padrões arquiteturais aplicados a sistemas móveis, especialmente relacionados à comunicação de dados e concorrência

# Desafio 2: Implementar um sistema de autenticação simples utilizando um serviço de autenticação como o Firebase Authentication

## Objetivo

- Utilizar o Firebase Authentication para adicionar autenticação de usuários na aplicação

## Fluxo de trabalho

1. [Configuração do Firebase Authentication](https://firebase.google.com/docs/auth/web/start?hl=pt-br)
    - Criar um projeto Firebase e habilitar o Firebase Authentication com email e senha

2. [Integração no Frontend](https://rnfirebase.io/auth/usage)
    - Implementar um formulário de login e cadastro, onde os usuários podem registrar e autenticar-se

3. Validação de Sessão
    - Implementar lógica para verificar se o usuário está autenticado antes de acessar certas partes da aplicação

4. Logout e Gerenciamento de Sessão
    - Adicionar uma funcionalidade de logout e verificar a sessão ativa

5. Conclusão e Testes
    - Testar o sistema com diferentes usuários e documentar o fluxo de autenticação e o funcionamento esperado

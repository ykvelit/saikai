# Oficina 1: Construção de uma aplicação simples utilizando React Native ou Flutter

## Objetivo

- Criar uma aplicação básica em React Native ou Flutter, incluindo navegação, exibição de dados e interações simples

## Fluxo de trabalho

1. Configuração do Ambiente
    - Iniciar com a configuração do ambiente de desenvolvimento (Node.js, Android Studio, Xcode para React Native; e Dart SDK e Flutter CLI para Flutter)

2. Estrutura do Projeto
    - Criar uma estrutura básica de pastas e arquivos, utilizando a CLI da tecnologia escolhida para gerar o projeto inicial

3. Criação da Interface de Usuário (UI)
    - Implementar uma tela inicial que exiba uma lista de itens, como um feed de notícias ou produtos
    - Adicionar uma tela de detalhes que exiba mais informações ao clicar em um item

4. Navegação
    - Configurar a navegação entre telas utilizando o React Navigation (para React Native) ou Navigator (para Flutter)

5. Interatividade
    - Adicionar funcionalidades interativas, como um botão que altera o estado de um item

6. Conclusão e Revisão
    - Revisar o projeto para garantir que a navegação, a exibição de dados e as interações funcionem conforme o esperado

# Oficina 1: Construção de uma aplicação simples utilizando React Native ou Flutter

## Objetivo

- Otimizar o desempenho da aplicação utilizando técnicas de carregamento eficiente

## Fluxo de trabalho

1. Revisão do Projeto Atual
    - Analisar a estrutura do projeto para identificar pontos de melhoria de desempenho

2. Lazy Loading
    - Implementar carregamento sob demanda para componentes e dados que não precisam estar disponíveis de imediato
    - Exemplo: Carregar imagens ou conteúdo de uma lista apenas quando o usuário rola até eles
    
3. Otimização de Imagens
    - Reduzir o tamanho de imagens através da compressão e uso de formatos adequados
        - Implementar um recurso para carregar versões de baixa resolução de imagens e substituí-las por versões de alta resolução quando necessário

4. Uso de Cache
    - Implementar o armazenamento em cache de dados para reduzir requisições ao backend

5. Análise de Desempenho
    - Utilizar ferramentas de análise de desempenho (como o React Native Performance Monitor ou Flutter DevTools) para monitorar e avaliar as melhorias

6. Conclusão e Revisão
    - Documentar as mudanças feitas e os ganhos de desempenho obtidos
